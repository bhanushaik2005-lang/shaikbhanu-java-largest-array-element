# Java Largest Element in an Array

A simple Java program to find the largest element in an array.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-java-largest-array-element`

## File Name

`LargestElement.java`

## Description

This program accepts elements of an array from the user and finds the largest element.

## Features

* Accepts array elements from the user
* Compares each element
* Finds the largest element
* Displays the largest value

## Requirements

* Java JDK 8 or later

## How to Run

Compile the program:

```bash
javac LargestElement.java
```

Run the program:

```bash
java LargestElement
```

## Example

```text
Enter number of elements: 5
Enter 5 elements:
10 45 23 67 32
Largest element in the array: 67
```

## Algorithm

1. Read the number of elements.
2. Read the array elements.
3. Assume the first element is the largest.
4. Compare it with the remaining elements.
5. Update the largest value whenever a larger element is found.
6. Display the largest element.

## Time Complexity

**O(n)**

## Space Complexity

**O(n)**
